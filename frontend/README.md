# TRACE — Frontend Package

React + Vite frontend for TRACE (CASCADE '26 Problem Statement 4.2: The Black Hole Ledger).

## Status
- **Phase 0:** Build pipeline verified via `npm run build`.
- **Phase 5 (Planned):** Full exploratory dashboard, transfer graph visualization, and REST API integration.

## Scripts
- `npm run dev`: Launch local Vite development server
- `npm run build`: Production build (outputs to `dist/`)
- `npm run preview`: Preview production build
